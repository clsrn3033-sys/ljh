# 하드웨어 변경 기준

| 구분 | ver1 적용 목표 | 상태 |
|---|---|---|
|보드|Raspberry Pi4B ARM64|대상 확정, 실물 미시험 |
|화면|5인치15핀 DSI800×480 가로·정전식·약60Hz 목표|제품·panel/touch 컨트롤러 미확정 |
|입력/출력|직접KMS, evdev, backlight sysfs|어댑터 구현. 실제경로 미확정 |
|센서|INA226/BH1750/DS3231, Pi CPU 내부 온도|주소 예정0x40/0x23/0x68. 실제3.3V/풀업·주소 미검증 |
|배터리|2S, 사용자 제시8.4V 완충 정보|셀·용량·BMS 차단전압/전류 미확정 |
|Pi 전원|별도5V 강압·부하 정격 검증|부품/회로 미확정.8.4V 직접 공급 금지 |
|NTC|100K B4100→충전기 NTC|Pi GPIO/ADC 연결 안 함 |
|전원 종료|OS sync/log/종료만, 이후 배터리 전원은 별개|GPIO latch 미구현 |
|제외|SPI LCD 출력,ADS1115,B3950×2,분압,배터리/케이스 온도UI,부저,진동,SATA|관련 기능 추가 안 함 |

[전체 설계·전원 블록](../docs/PI4B_HARDWARE_REV_A.md) · [설계 JSON](../hardware/mebs-pi4b-revA.json) · [배선 CSV](../hardware/wiring-pi4b.csv)

센서 기본 연결: 물리1=3.3V,3=GPIO2 SDA,5=GPIO3 SCL,6=GND. 실제 모듈의3.3V 로직과 풀업을 확인한다. INA226의VS전원과VBUS/IN± 측정 단자는 구분한다. 충전기의 충전/밸런싱 보호 목록을 별도BMS 방전 보호로 간주하지 않는다.

현재는 기능 블록·소프트웨어 연결부 설계다. 확정 부품·실측 없이 조립용 회로/PCB/Gerber가 완성됐다고 보고하지 않는다.
