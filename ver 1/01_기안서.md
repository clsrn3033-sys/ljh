# MEBS 경량 자동 백업 시스템 개발 기안서

- 문서 기준: ver1 /2026-10-18 /개발 인계용.
- 프로젝트: MEBS Auto Backup System.
- 저장소: https://github.com/clsrn3033-sys/ljh
- 제작자 표기: 제49기 보도부 이정헌 / Produced by 이정헌.

## 추진 목적

촬영 현장에서 PC 없이 원본 SD카드를 외장 저장장치에 백업하고 SHA-256으로 확인할 수 있는 휴대형 전용 장치를 개발한다. Raspberry Pi4B와 Buildroot 경량 OS를 기준으로800×480 DSI 터치 UI, 센서 상태, 설정 저장, 안전 종료를 통합한다.

## 개발 범위

1. 기존 백업 엔진·파일/폴더/XML 보존·검증 경계 유지.
2. 제공 MEBS 로고 기반 부팅·메인·설정·오류·종료 UI.
3. USB 연결 순서에 따른 역할 판별과 모호 상태 차단.
4. INA226/BH1750/DS3231 및 CPU 내부 온도 연결부.
5. 밝기·자동 밝기·야간·대기·터치 잠금 설정과 영속 저장.
6. 백업 중 설정 조작 및 완료 후 안전 종료 예약.
7. 별도 Pi4B `.img` 빌드, 가상디스크 QEMU 검증, 이후 실물 검증.

## 유지·제외 원칙

기존 이미지·소스·승인 UI/제작자 표기를 보존한다. 원본 자동 삭제·자동 포맷·검증 실패 후 포맷은 허용하지 않는다. SPI LCD 출력, ADS1115, B3950 NTC, 배터리/케이스 온도 UI, 부저·진동·내부 SATA, 미확정 GPIO 전원 차단을 제외한다.100K B4100 NTC는 충전 모듈 전용이다.

## 산출물

개발 소스, 하드웨어 변경표·전원 기능 블록·배선 계획, 재현 명령, 모의 프리뷰, 테스트 로그, 실제 빌드가 성공한 경우에만 `.img`/SHA-256/부팅 로그를 제공한다.

## 의존 조건

다운로드 도메인 접근, 실제 LCD/터치 모델, 션트·전류 정격, 배터리 셀/BMS/강압기 자료가 필요하다. 하드웨어 값이나 비용·납기·실측 결과는 확인 없이 확정하지 않는다. 현재 코드는 소프트웨어 인계 기준이며 PCB 제작/전기 검증 완료 상태가 아니다.
