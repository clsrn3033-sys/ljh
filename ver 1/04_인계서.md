# 다른 기기에서 이어받기

## 저장소와 기본 순서

```sh
git clone https://github.com/clsrn3033-sys/ljh.git
cd ljh
```

1. 저장소 루트 `AGENTS.md`, 이 폴더 README/결정사항/개발현황을 읽는다.
2. `git status`와 `git log -1`을 기록한다. 기존 수정·원본 이미지는 보존한다.
3. UI 확인 후 소프트웨어 테스트, 다운로드 접근, 실제 이미지 빌드 순서로 진행한다.
4. build 결과가 없으면 이전 Debian/QEMU 파일이나 빈 파일을 새 `.img`로 제공하지 않는다.

## Debian13 x86_64에서 실행한 재현 명령

호스트 요구: Python3.12+·venv·pip, git·make·gcc/g++·patch·perl·file·wget·unzip·xz·APT·dpkg-deb 및 Debian archive keyring. 새 OS에는 필요한 호스트 도구를 정상 패키지 설치로 준비한다. Windows는 Linux/WSL2 빌드 환경이 필요하며 Windows 명령 프롬프트에서 직접 검증하지 않았다. ARM 호스트에서는 `host-tools.py`가amd64 패키지를 받아오는 점을 수정/검증해야 한다.

```sh
python3 scripts/host-tools.py
python3 -m venv .venv
.venv/bin/python -m pip install Pillow==12.3.0
export MEBS_FONT="$PWD/.local-build/sysroot/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc"
.venv/bin/python -m unittest discover -s tests -v
PYTHONPATH="$PWD" .venv/bin/python scripts/preview-journey.py
```

host-tools는 APT 서명/해시 검증 후 `.local-build`에 추출한다. 시스템 `/usr` 설치·root 권한이 필요 없다. 현재118 tests가 기준이다. 새 수정 후 필요한 검증을 수행하고 결과를 기록한다.

## Buildroot 준비·이미지 빌드

```sh
mkdir -p vendor
git clone --depth 1 --branch 2026.08 https://github.com/buildroot/buildroot.git vendor/buildroot-2026.08
git -C vendor/buildroot-2026.08 rev-parse HEAD
# 기대: 813cbac680a73092e1ebb86da72972c44573145c
scripts/pi4-dsi-image.sh
```

성공할 때만 `output/pi4-dsi-800x480/images/sdcard.img`가 생성된다. 이 명령은 SD카드를 flash하지 않는다. 출력 파일 크기/sha256, Buildroot/kernel 최종 구성·로그를 별도 기록한다. 기존 출력/원본을 덮어쓰지 않는다. `.config`는 기기 절대경로를 포함하므로 이전 output을 그대로 복사하는 대신 새 output에서 생성한다.

현재 차단 도메인은 `evidence/network-domains.txt`에 있다. 제한 환경에서는 관리자 UI의 정상 허용/게시 경로를 사용한다. TLS/APT 서명/Buildroot 해시를 끄거나 프록시를 우회하지 않는다. 다른 PC에서 접근된다는 추정 대신 실제 다운로드 응답을 확인한다.

## 실물 Pi4 식별

기존 부팅 OS가 있는 실제 Pi4B에서:

```sh
python3 scripts/pi4-hardware-report.py --output hardware-report.json
```

이미 kernel에 등록된 DRM/I²C/touch 정보를 읽기 전용으로 수집한다. 실제 패널/터치명·센서3.3V·션트·BMS·강압기 자료를 확인한 뒤 전용 profile의 hardware.json을 수정한다. 기본 출력/센서가 비활성인 현재 이미지를 빌드해도 DSI GUI가 자동 검증되는 것은 아니다. 미설정값을 임의로true로 바꾸지 않는다.
