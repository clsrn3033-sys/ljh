# 사용자 결정사항 — 최신 기준

1. 이번 목표는 **Raspberry Pi4B용 Buildroot 경량 ARM64 `.img`**다. 과거 x86 ISO/Windows-QEMU Debian 패키지는 별도 참조다.
2.800×480 가로 UI를 사용한다. 제공한 MEBS 로고·검정·청록색·얇은 게이지와 페이드를 기준으로 한다.
3. 제작자 표기는 **제49기 보도부 이정헌 / Produced by 이정헌**이다. 첨부JPEG 원본의이정원은 원본 보존상 그대로지만 실행표기는 사용자 정정값을 사용한다.
4. 부팅→메인→빠른 설정 프리뷰를 확인한 뒤 사용자가 UI를 결정했다. 임의 전면 재디자인하지 않는다.
5. 첫 연결USB=백업 대상, 두 번째USB=원본SD다. `수정금지.txt/.text`를 요구·생성·삭제하거나 그 존재로 구분하지 않는다.
6. 순서가 모호하면 자동 백업을 막고 모두 분리 후 순서대로 재연결한다. 파일시스템을 근거로 순서를 뒤집지 않는다.
7. 백업은 원본 폴더/XML·파일 보존과SHA-256 검증을 유지한다. 부족 용량은 필요/잔여를 표시하며 포맷하지 않는다.
8. 원본 삭제/포맷은 자동 실행하지 않는다. 실제 수동 포맷 엔진은 아직 없다.
9. 백업 중 설정 조작은 가능하고 복사/검증은 계속된다. 종료는 성공·정상분리 뒤 예약 실행한다.
10.8.4V는 배터리 완충 정보이며 BMS 방전 한계·션트·용량 정보가 아니다. 임의 수치 확정 금지.
11. 하드웨어 전원 차단 GPIO, 부저·진동·ADS1115·배터리/케이스 온도·내장SATA는 제외한다.
12. 기존 원본 이미지·보존 폴더는 변경/삭제/재빌드하지 않는다.
13. **이번 요청으로 기존GitHub ljh에 ver1 문서·소스·프리뷰 인계 게시가 승인됐다.** 다른 세션/과거문서의 게시 금지는 이번 인계 게시에 적용하지 않는다. 새 저장소 생성/원본 대용량 이미지 재게시/force push까지 승인된 것은 아니다.
