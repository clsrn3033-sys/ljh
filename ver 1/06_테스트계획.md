# 테스트 계획과 인계 시 증거

|필수 항목|호스트/모의 실시|추가 필요한 검증|
|---|---|---|
|800×480UI|실제 렌더러 PNG/RGB·육안 확인|Pi4 DSI 출력|
|설정 열고 닫기|제스처 상태/프리뷰|실제 swipe|
|터치 버튼|좌표·유실/다중 접촉·확인/잠금 모의|evdev 매핑·정전식 터치|
|밝기|슬라이더·필터·설정 저장|물리 backlight/조도|
|온도·배터리|모의 값·변환/오류|실물 측정/보정|
|백업 중 설정|실제 임시 파일 복사 worker+설정 조작|Pi 장시간 I/O|
|백업 중 종료 예약|즉시 종료 없음·예약 경계|가상 OS/실물 OS|
|완료 후 종료|sync/log/mock poweroff 순서|실제 종료/언마운트|
|SD 제거|device inventory 제거 오류|가상 USB hotplug 후 실물|
|외장 제거|같음|같음|
|공간 부족|실제 크기·mock statvfs·오류|가상 파일시스템 ENOSPC|
|검증 실패|실제 복사본 변조→실패|가상 USB/실기기 흐름|
|전원 차단 복구|프로세스SIGKILL·미완료 보존·새 재시도|가상 OS 중단 및 실제 전원 시험|
|RTC 복원|BCD/OSF/UTC clock setter 모의|실물RTC·재부팅|
|센서 미연결|I²C/thermal open 실패 주입|실제 미연결/재연결|

추가 실시: 제공 로고 원본/파생 hash, 정상/손상PNG와fallback, zipapp asset 로딩, 션트정격·전압범위·미확정BMS/DSI 설정 거부. 합계118개 통과.

원칙: 새 테스트는 임시 파일/가상디스크만 사용한다. 사용자 물리 저장장치를 포맷/삭제하는 시험 금지. 기존 UI 원본JPEG/과거 이미지 보존. 테스트가 실행되지 않았으면 미실시, 실패했으면 실패로 기록한다. 가상 신호를 실측으로 보고하지 않는다.

현재 evidence 로그는 이전 환경에서 수집한 결과다. 새 기기에서 실행한 결과에는 실행 명령·환경·exit code·파일hash·시간측정의 시작/종료 기준을 다시 기록한다.
