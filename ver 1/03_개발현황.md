# 개발 현황 / 검증 범위

## 구현된 소프트웨어

- `backup.py`: 구조/원본/파일/XML·POSIX 메타데이터·xattr·SHA-256 보존, 임시 작업→원자 커밋. 대상ext4, 원본vfat/exfat/ntfs/ext4.
- `devices.py`, `appliance.py`: 순서 역할/장치 식별, 원본 read-only, 용량, 복사·독립 검증·syncfs·정상 unmount.
- `runtime800.py`: 표시와 분리된 backup worker·센서 thread·UI loop. 화면 미연결 대기 때문에 복사를 막지 않음.
- `controls.py`, `settings.py`: 제스처·잠금·화면 대기·밝기·원자 저장·종료 확인/예약. 복사 실패 시 예약 취소.
- `sensors.py`, `rtc.py`, `hardware_profile.py`: 센서 변환/밝기 필터/RTC UTC·OSF/설정 검증. 실물 미확정 기본 비활성.
- `ui800.py`, `boot_animation.py`, `logo_asset.py`: 검정·청록 테마, 사용자 로고, 진행 상태·오류·전원 화면.
- `drm_presenter.c`, `outputs.py`, `touch.py`: 직접KMS/fbdev와 evdev. X11/데스크톱 불필요.
- `buildroot/board/mebs-pi4-dsi`: 별도 profile, 커널 fragment, init, 읽기 전용 root,8MiB OS 설정 파티션.

## 실제 검증 결과

**호스트 자동 테스트118개 통과**. 상세 `evidence/pi4-dsi-tests.log`. Python3.12/Pillow12.3.0, Debian13 x86_64에서 실시했다. 원본 엔진/프로세스 중단·변조, UI/예약/모의 mount/센서/RTC, 제공 로고 hash/zipapp, 하드웨어 설정 거부를 포함한다.

C DRM helper 호스트 컴파일은 성공했으나 DRM scanout을 시험하지 않았다. UI 프리뷰는 실제 렌더러에 모의 값을 주어 생성했고 실제 부팅/복사 녹화가 아니다.

## 현재 실패·미구현

- Buildroot host-pkgconf-2.3.0 다운로드에서 proxy CONNECT403, make exit2. 새 `.img` 없음.
- 네트워크 enabled 권한을 정식으로 받아도 해당 source proxy403은 그대로였다.
- 클라우드 환경 초안에 허용 도메인·재현 지침은 저장됐으나 적용/게시됐다는 확인은 없다. 그 초안은 다른 기기에 자동 전송되는 설정이 아니다.
- QEMU ARM64/실물 Pi4B 부팅·DSI/touch/센서/BMS/전원·재부팅 설정 영속성 미시험.
- 분류 규칙·SD 포맷 미구현. GPIO 실제 전원 차단 없음.
- 기존 embedded 로고 데이터는 손상된 그대로 보존했고, 새로 첨부된 정상 JPEG에서 실제 logo mask를 추출해 기본 사용한다.

로그 경로의 이전 기기 절대경로는 참고 기록이다. 새 기기에서는 현재 clone 경로에 맞춰 스크립트를 실행한다. 오래된 문서·예시의 Produced by 이정원, OrangePi 최종/480×320/x86 ISO 등은 최신 개발 목표가 아니다.
