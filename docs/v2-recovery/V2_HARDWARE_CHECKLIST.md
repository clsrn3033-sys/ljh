# Raspberry Pi 4B 실물 확인표

현재 체크 상태: 아래 항목 모두 **HARDWARE NOT TESTED**. 이 환경에는 Pi의
전압·ACT LED·UART 로그·DSI 패널 정보·배터리 부품 모델의 실측 자료가 없다.
사용자는 관련 부품이 AliExpress 발주품이라 실물 검증은 나중에 진행한다고 확인했다.

| 확인할 것 | 필요한 연결·자료 | 통과 기준 / 기록 |
|---|---|---|
| 전원 | 정격 5V 전원, USB 부하, 부하 중 측정 가능한 계측기 | Pi 5V/GND의 부팅·USB 연결 순간 전압과 ACT/PWR LED 기록. 2S 8.4V를 Pi 5V에 직결하지 않음 |
| 부팅 원인 분리 | 폐기 가능 microSD, micro-HDMI, USB 키보드, 가능하면 3.3V UART | ACT LED 패턴, 시리얼 로그, 모니터 화면, 전원 전압을 함께 기록. 빨간 PWR LED만으로 EEPROM 고장 단정 금지 |
| SD 이미지 | 새 후보 IMG checksum, Etcher 또는 동등한 검증 기록 | 기록 전 대상 카드 모델·용량 확인, 기록 후 검증, boot FAT32·cmdline/config 확인. 기존 카드/이미지 보존 |
| EEPROM | 장치의 현재 부트 순서/버전 읽기 | 이미지·전원·카드 문제를 먼저 제외. 필요성 확인 전 복구/업데이트 금지 |
| DSI/touch | 5인치 800×480 패널 **정확한 모델·케이블·컨트롤러** | 800×480 출력, 부팅 전환, 정전식 터치, 백라이트 경로 실측. 현재 overlay 미확정 |
| USB 역할 | 폐기 가능한 ext4 외장 저장장치와 샘플 FAT32 카드리더 | 첫 USB 대상, 두 번째 원본, 동시 삽입 차단, 장치 교체/해제 검증 |
| 데이터 | 샘플 사진·영상·XML 및 별도 PC | 폴더·메타데이터·SHA-256·기존 데이터 보존, 재연결/강제 종료 후 미완료 상태 확인 |
| DC-DC/BMS | 부품 모델, 데이터시트, 션트 정격, 배선도 | 2S 방전 전압 범위·5V 3A 연속·순간 강하·충방전 동시 사용·셀 밸런싱 확인 |
| INA226 | 실제 션트 저항·극성·I²C 주소·3.3V 논리 확인 | 알려진 부하와 전압/전류 계측값 비교 후에만 hardware.json 활성화 |
| DS3231 | 모듈 모델/전원/배선, 배터리 또는 슈퍼캡 | 전원 차단 뒤 시간 유지·UTC 날짜 폴더 검증 후에만 활성화 |
| 충전 NTC | 100K B4100 모듈 데이터시트 | 모듈 자체가 온도를 사용하는지 확인. Pi GPIO 센서라고 표시하지 않음 |
| 종료 | UI 안전 종료 및 전원 차단 회로 설계 | OS sync/unmount/poweroff와 실제 배터리 전원 차단을 따로 측정. GPIO 차단 코드는 비활성 |

실기기 결과가 제출되기 전에는 위 항목을 PASS로 바꾸지 않는다.
전원/패널 부품의 모델명이 없어 특정 데이터시트 적합성도 아직 판단할 수 없다.
